# Project: Hypotenuse Calculator
## Description
This calculator solves for the hypotenuse using the pythagorean theorem (a^2+b^2=c^2)
## How to Run
In order to run the program, you need to download the python (py.) file from the repository
## Input Needed
This calculator needs exactly two inputs from the user(a, and b). Both are float, which means decimals are allowed
## Sample Output
Enter a number for a: 6
Enter a number for b: 7

The hypotenuse is: 9.22
